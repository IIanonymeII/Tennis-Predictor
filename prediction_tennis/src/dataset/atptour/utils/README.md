# Tennis-Predictor – ATP Tour Utils

This folder contains **utility functions** that are shared across multiple modules of the Tennis-Predictor project.  

These utilities are designed to **reduce code duplication**, simplify common tasks, and improve overall project maintainability.


---

## ⚙️ Files Overview


>- **`config.py`**  
 Handling configuration and constants.

>- **`flashscore_utils.py`**  
 Extracting and processing tournament data.

>- **`player_utils.py`**  
 Managing player information, including name normalization and similarity matching.
